# Vibe Coding 青少年课程 · 15 节课拆解方案

> 受众：10–15 岁青少年 ｜ 工具：全程使用 ZCode 实现 Vibe Coding
> 原项目来源：第1课《认识 Vibe Coding》、第2课《与 AI 对话》、第4课《让作品动起来》

---

## 一、整体设计理念

把三个"成品案例"分别拆成 5 节循序渐进的课，让学生**从零开始、亲手复刻**出与原项目相同质量的完整作品。每节课再细分为 **part1 / part2 / part3** 三个环节，对应"讲解 → 实践 → 验收"的节奏，并在 part1 之后安排**阶段 Demo 展示**环节。

| 环节 | 时长 | 作用 |
|------|------|------|
| part1 · 讲解与演示 | 15 分钟 | 老师拆解本节目标，演示原项目对应模块，教提示词方法 |
| 阶段 Demo 展示 | 约 5 分钟 | 老师打开本课 `demo/demo.html` 给学生看——这是本节课做完后的阶段成果（可不完善），让学生先看到目标再动手复刻 |
| part2 · 动手实践 | 25 分钟 | 学生用 ZCode + Vibe Coding 复刻本节模块 |
| part3 · 验收与反馈 | 5 分钟 | 运行测试、同伴互评、记录修改 |

> **阶段 Demo 说明**：每个案例的 5 节课各有一个分阶段 Demo，由原项目（第1/2/4课源文件）**完全移植并分阶段优化**而来。前面的课是"不完善"的阶段版本（只含本课模块），第 5 节课是完整移植原项目的最终成品。学生对照 Demo 看到每节课的进步。

每节课均产出：
- **教案**（Typst 格式，可打印）
- **课件 PPT**（HTML 格式，reveal.js，可在浏览器全屏播放）
- **阶段 Demo**（`demo/demo.html`，浏览器打开即可演示）

## 二、三个案例拆解总表

### 案例一：个人名片网页（对应原第1课·认识 Vibe Coding）

原项目：`hello_world.html` —— 一个个人介绍网页（标题、自我介绍、照片占位、说明框）。

| 课次 | 主题 | 本课目标 |
|------|------|----------|
| 第1课 | 认识网页三件套 | 理解 HTML、CSS、JavaScript 与浏览器的关系，用提示词生成第一个本地网页 |
| 第2课 | 文字与排版 | 复刻标题、自我介绍段落、说明框，掌握文字类标签 |
| 第3课 | 颜色与背景 | 复刻淡蓝背景、白色卡片、圆角阴影，掌握 CSS 美化 |
| 第4课 | 图片占位与布局 | 复刻照片占位区域，理解 div 布局与居中 |
| 第5课 | 打磨与作品展示 | 整合所有模块，做一次 before/after 优化，完成本地作品展示 |

### 案例二：矿洞救援 3D 游戏（对应原第2课·与 AI 对话）

原项目：`矿洞救援.html` —— Three.js 3D 网格游戏，矿工收宝石到出口。

| 课次 | 主题 | 本课目标 |
|------|------|----------|
| 第1课 | 从模糊到清晰 | 体验"简陋2D版 vs 清晰3D版"，学 WHO-WHAT-HOW 提示词 |
| 第2课 | 搭建3D场景 | 用提示词生成矿洞地板、墙壁、灯光（Three.js 基础） |
| 第3课 | 玩家与移动 | 复刻矿工角色 + 方向键移动 + 网格碰撞检测 |
| 第4课 | 宝石与岩浆 | 复刻收集宝石、踩岩浆扣血、出口判定等游戏逻辑 |
| 第5课 | HUD与动画打磨 | 复刻分数/生命/倒计时 HUD，宝石浮动动画，最终验收 |

### 案例三：乐高 McLaren 赛车（对应原第4课·让作品动起来）

原项目：`lego_mclaren_racer.html` —— Three.js 三车道赛车，换道躲避障碍。

| 课次 | 主题 | 本课目标 |
|------|------|----------|
| 第1课 | 交互事件入门 | 理解"当用户…时执行…"，做按钮点击反馈小 demo |
| 第2课 | 赛道与相机 | 用提示词生成三车道公路、草地、相机视角 |
| 第3课 | 赛车与换道 | 复刻乐高风格赛车 + 左右换道 + 键盘/按钮控制 |
| 第4课 | 障碍与碰撞 | 复刻障碍物生成、速度递增、碰撞结束逻辑 |
| 第5课 | HUD与音效打磨 | 复刻距离/速度/最佳记录 HUD、音乐开关，最终验收 |

## 三、目录结构

```
VibeCoding15课拆解课程/
├── _总览/
│   └── 课程总览.md            ← 本文件
├── _模板/
│   ├── 教案模板.typ           ← Typst 教案模板（含 demo-block 等组件）
│   └── 课件模板.html          ← HTML PPT 模板
├── 案例一_个人名片网页/
│   ├── 第1课/  (part1/ part2/ part3/ + demo/ + 教案.typ + 教案.pdf + 课件.html)
│   ├── 第2课/  ...
│   └── ...
├── 案例二_矿洞救援3D游戏/
│   └── ...
└── 案例三_乐高McLaren赛车/
    └── ...
```

每节课文件夹内：
- `教案.typ` —— 可用 Typst 编译为 PDF 打印（`typst compile --root . 教案.typ`）
- `教案.pdf` —— 已编译的可打印教案
- `课件.html` —— 浏览器打开即可全屏授课（reveal.js）
- `demo/demo.html` —— **阶段 Demo**，浏览器打开即向学生演示本课阶段成果
- `part1/` `part2/` `part3/` —— 分别存放三个环节的学生提示词参考、代码片段、验收清单

## 四、阶段 Demo 分阶段优化对照表

每个案例的 5 个 Demo 由原项目完全移植、逐课累加模块，体现"分阶段优化"：

### 案例一·个人名片网页（移植自原第1课 hello_world.html）
| 课次 | Demo 阶段 | 累加的模块 |
|------|-----------|-----------|
| 第1课 | 网页骨架 | 标题 + 文字（无样式） |
| 第2课 | 文字与排版 | + 多段自我介绍、说明框（仍无颜色） |
| 第3课 | 颜色与背景 | + 淡蓝背景、白色圆角卡片、阴影 |
| 第4课 | 图片占位与布局 | + 灰底虚线占位区 |
| 第5课 | **完整成品** | 完全移植 hello_world.html（所有模块齐全） |

### 案例二·矿洞救援3D游戏（移植自原第2课 矿洞救援.html / 矿洞救援_简陋2D.html）
| 课次 | Demo 阶段 | 累加的模块 |
|------|-----------|-----------|
| 第1课 | 简陋2D版 | 移植自简陋2D版（反例：模糊提示词的产物） |
| 第2课 | 3D矿洞场景 | 3D 地板 + 墙壁 + 灯光（无矿工） |
| 第3课 | 矿工 + 移动 | + 矿工角色、方向键移动、边界检测 |
| 第4课 | 宝石 + 岩浆 + 逻辑 | + 收集、扣血、出口判定（未打磨） |
| 第5课 | **完整3D成品** | 完全移植 矿洞救援.html（HUD + 动画 + 装饰） |

### 案例三·乐高 McLaren 赛车（移植自原第4课 lego_mclaren_racer.html / interactive_effects.html）
| 课次 | Demo 阶段 | 累加的模块 |
|------|-----------|-----------|
| 第1课 | 交互事件 Demo | 移植自 interactive_effects.html（点击/悬停反馈） |
| 第2课 | 赛道 + 相机 | 3D 三车道公路 + 草地 + 相机（无赛车） |
| 第3课 | 赛车 + 换道 | + 乐高赛车、左右换道、车轮旋转（无障碍） |
| 第4课 | 障碍 + 碰撞 | + 障碍生成、碰撞结束、速度递增（乐高车） |
| 第5课 | **完整赛车成品** | 完全移植 lego_mclaren_racer.html（McLaren 模型 + HUD + 音效） |
