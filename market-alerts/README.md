# 行情提醒器：数据类型与指标模块

成长报告记录的个人工程探索是 OKX 多币种行情提醒与终端看板。本次提取其中独立的纯逻辑部分：行情数据类型、合成行情提供器、指标计算与原有指标测试。

`okx_alert/indicators/` 使用 `Decimal` 处理 SMA、EMA、RSI、MACD、Bollinger、ATR 等指标；注册表和引擎把指标定义与调用分开。`marketdata/` 提供类型、协议、标识映射和确定性 fake provider，方便在无真实行情时验证。

本精选子集要求 Python 3.11+，仅依赖标准库。原有指标测试入口为：

```sh
python -m unittest discover -s tests -p test_indicators.py -v
```

本次归档已运行上述标准库测试，20 项全部通过；未执行行情请求。此快照不包含完整终端 UI、行情提醒服务和真实 provider，不能直接启动原项目的 dashboard；也没有包含交易子系统、用户规则、账户凭证、状态数据库、交易日志、市场数据集或第三方模型仓库。通过原项目 README 可确认其提醒器定位；个人后续探索中的其他模块不据此统一描述为“只提醒”。
