# 电极拓扑无关 EEG 表征：几何与参考实验选集

这是从个人研究工作区整理的精选源码快照，保留 AI 辅助开发痕迹与上游方法归属。它不是完整实验归档，也不是已发表成果。整理时未执行训练、仿真或重新计算科研结果；以下数字均为原工作区历史记录。

研究边界是电极集合、位置、导联与参考变化时的表征泛化。接受可变数量通道、泛化未见集合、泛化未见位置、应对参考变换是不同能力，不能互相替代。

本快照精选 [几何与参考实验模块](experiments/L2-measurement-geometry/)，包含共享模板几何、逐轴坐标归一化、球面求积、参考变换、信息可辨识性分析、审计与总入口。个人范围为实验定义、实现与边界核验；MNE 标准电极模板和 SciPy 数值方法属于上游依赖。

## 运行范围

该小模块的本地 Python 文件成组保留；依赖 NumPy、SciPy、MNE。总入口为 `experiments/L2-measurement-geometry/run_all.py`，其调用的四个实验脚本均在目录中。运行会生成结果文件，本次未执行，因此不声称该快照已经重现历史数字。

完整研究中的 LuMamba、REVE、CBraMod 适配器、训练权重、真实 EEG 和大型评价流水线不在此选集。本模块的模板/合成结果不能当作真实 EEG 任务收益，也不能当作任意电极布置已泛化的证据。
