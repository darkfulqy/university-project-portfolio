# 科研工作流与论文阅读

这部分记录个人的研究组织方式及文献阅读活动。来源为成长报告第 3—5 页与本地研究工作区，不把第三方论文或工具实现作为个人产出。

## 研究工作方式

1. 先定义问题、研究范围与可否证的假设。
2. 建立基线、固定数据划分和指标，再记录对照实验。
3. 将想法与证据关联，保留被否决的方法分支和否决原因。
4. 区分探索性观察、经过复核的结果和论文中可支持的结论。
5. 使用 Claude Code 与 Codex 辅助代码、实验和写作复核；本人对结果解释与学术表达负责。

报告记载本人维护了 MinerU 论文转换、投稿适配自评和论文追踪等辅助技能。该目录是归纳说明，不包含这些工具的完整源码，也不把工具使用次数等同于研究产出。

## 阅读与投稿准备

本地有两期论文速览、一份 EEG 与测试时适配阅读清单及稿件评估材料。完整来源位置列入私有本地索引；公开仓库不重新发布第三方论文全文和私人审稿记录。
