## 如何使用

各目录提供工程范围、运行前提和归档限制。源码为历史工程精选快照，整理提交日期不代表项目开始日期。团队成果不等同于个人独立完成；个人分工见对应说明。

完整大学经历时间线、课程报告、奖项核验状态和本地证据路径另外保存在私有本地整理材料中。本仓库不包含学籍证件、联系方式、生产数据、聊天附件、第三方全文资料、模型权重或账号凭据。

本次整理仅做静态语法、路径和敏感信息检查；没有重新运行完整训练、部署、所有课程实验或所有测试。未另行授予原项目或第三方内容的使用许可，各来源已有权利归属保持有效。
