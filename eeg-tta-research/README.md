# MI-EEG 跨会话基线与 TTA 方法选择

这是从个人研究工作区整理的精选源码快照，保留 AI 辅助开发痕迹与上游方法归属。它不是完整实验归档，也不是已发表成果。整理时未执行训练、仿真或重新计算科研结果；以下数字均为原工作区历史记录。

研究主线是比较训练日与目标日的 EEG 解码差异，并检验无标签信息能否支持逐日选择测试时适配方法。个人工作范围是实验组织、接口与评估实现、统计复核、分析和写作；EEGNet 与各 TTA 算法来自已有研究。

- [跨会话小基线](xsession-baseline/)：数据读取、EEGNet、适配、分析与作图的完整小模块源码。
- [方法选择与联合重采样选段](selector-excerpts/)：原研究中的策略和统计核心选段，依赖原工作区的结果格式及周边流水线。
- [历史进展与限制](HISTORICAL_FINDINGS.md)：说明投稿状态、负结果与修订边界。
- [方法归属与依赖](ATTRIBUTION.md)。

## 运行范围

小基线需要 Python、NumPy、SciPy、scikit-learn、PyTorch，作图另需 Matplotlib；真实 EEG 数据没有纳入。原记录使用 BCI Competition IV-2a 的 T/E 两日数据、9 名被试、4 类、22 通道。准备有权使用的数据并确认脚本参数后，原流程入口为 `xsession-baseline/run_baseline.py` 和 `run_families.py`。本次仅做源码整理，未重新测试其环境或数据路径。

`selector-excerpts/` 是阅读用的精选模块，需回到完整原工作区才能重跑相应实验。本快照没有复现 10 月修订稿的全部代码、检查点、逐试次预测和统计产物，不能作为整篇论文的一键复现仓库。
