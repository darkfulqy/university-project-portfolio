# 社团组织与教学链方案

成长报告记录本人担任上海大学郁金香投资俱乐部社长，处理迎新、年审、活动报备与经费事务；本地材料支持 2026 年暑期已承担负责人工作，起始任期未单独核实。

2026-09-30 的《学生社团自有链建设方案》比较 Besu 私有链、公共测试网、FISCO BCOS 与 rollup，提出先用 Besu 教学链串联节点、钱包、合约、简单应用与运维交接的学习方案。

方案把活动凭证作为示例，区分社团记录与正式学籍／学分，考虑权限、撤销、备份、维护分工，以及教学实验与常驻服务的隔离。这体现的是需求分析与路线选择工作。

**状态：规划方案，未部署或压测。** 四周排期、并发指标和预算均为原方案的建议，不能写成已经建成并达到性能目标。本快照仅公开摘要，原方案与社团表格留在本地；不包含报名信息、成员联系方式、报销细节或账户资料。
