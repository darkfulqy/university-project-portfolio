# 基于 YOLO 的数字散斑相关法物体形变测量

大学生创新创业训练项目（2024.12—2025.04）。李卿阳担任技术负责人，承担项目的主要技术实现。

## 个人工作

- 构建散斑图像数据集，完成图像标注、训练前整理与样本质量检查。
- 基于 Python 与 YOLOv8（OBB 旋转框）识别散斑的形变、位移与旋转。
- 根据检测得到的 Anchor（角点）进行最小二乘多项式拟合，得到散斑位移网格。
- 结合相关物理方法与基于 MATLAB 的 Ncorr，计算物体的相关形变参数。

YOLOv8 与 Ncorr 是已有的开源模型与工具；项目工作在于把它们组合成数字散斑相关法的形变测量流程并完成实现。

## 与 C++ 课程作业的关系

拟合环节另以 C++ 实现最小二乘、高斯消元与网格拟合，并作为《计算思维实训1》课程作业提交，见[多项式拟合与形变测量](../coursework/grid-polynomial-fitting/)。
