# YOLOv8 形变材料散斑纹样检测

大一阶段参与的课外计算机视觉大创项目。项目使用 YOLOv8 识别形变材料上的散斑纹样；根据成长报告，李卿阳以项目成员身份承担数据准备与质量检查工作。

## 个人工作

- 构建与整理用于视觉检测的数据集。
- 进行图像标注、训练前文件整理和样本质量检查。
- 围绕数据来源、标注规范与可用性，为团队后续模型训练和评估准备输入。

这项经历体现了对计算机视觉项目中数据、标注和模型训练关系的早期实践。项目模型采用 YOLOv8，不把已有检测算法本身写为个人原创，也不将团队全部建模与训练工作归为个人独立完成。

## 与 C++ 课程作业分开记录

[多项式拟合与形变测量](../coursework/grid-polynomial-fitting/)是《计算思维实训 1》课程作业，用 C++ 完成最小二乘、高斯消元与网格拟合，原报告提到 YOLOv8-OBB 角点输入。它展示课程中的拟合计算部分；本目录单独展示课外 YOLOv8 计算机视觉项目及个人的数据工作。
