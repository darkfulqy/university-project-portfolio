# 8086 游戏逻辑自动测试

测试通过 NASM 组装成真实的 16 位机器码，在 Unicorn 的 x86 实模式 CPU 中执行。`test_game.py` 直接验证核心子程序；`test_main.py` 组装完整的 `main.asm`，模拟 BIOS/DOS 中断，验证启动、事件循环、输入及显存绘图。没有用 Python 重写一份游戏逻辑，也没有把 Python 当作游戏运行环境。

## 运行

在项目根目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install unicorn==2.1.4
.venv/bin/python -m unittest discover -s tests -v
```

需要 `nasm` 已在 PATH 中。Windows 的虚拟环境命令使用 `.venv\Scripts\python.exe`。

## 覆盖范围

- 7 种方块的 28 个旋转状态，4 格唯一性及连通性。
- 左右边界、顶部、底部和固定方块碰撞；寄存器及调用栈恢复。
- 水平移动、旋转失败、两格墙踢。
- 落点投影、软降、重力下降、硬降锁定、下一块生成。
- 1 至 4 行消除、下移压实，硬降与四行消除的组合计分。
- 等级变化及消行前等级的计分倍数，分数/行数饱和与速度下限。
- 出生位置堵塞结束、新游戏重置。
- 两个相同种子实例分别执行 2,500 次随机操作，检查一致性、合法位置及棋盘前后保护字节。
- 完整 COM 的标题等待、开始、暂停/恢复、重新开始和游戏结束按键限制。
- BIOS 键盘扫描码与 WASD 路径，处理按键时仍能触发自动下落。
- BIOS 计时低字回绕及午夜归零，暂停后的计时基准恢复。
- 双缓冲内容与 B800 显存的 4,000 字节复制、显存保护字节、分数文字、固定块、活动块、投影和预览颜色。
- ESC 退出时恢复原显示模式、活动页和光标状态，并调用 DOS 退出服务。

每个汇编调用都有指令数及超时上限。测试入口及符号表在临时目录生成，不影响正式游戏产物。棋盘前后的 `A5` 保护字节只占 32 字节，用于发现越界写入。

共 25 项测试。Unicorn 集成测试模拟中断并读取显存，可以发现逻辑与绘图数据问题；DOSBox-X 下真实的窗口显示、宿主键盘映射及实际游戏速度仍需在模拟器里检查，自动测试不能代替这部分体验验证。
