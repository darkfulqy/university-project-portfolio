# 2026 年课程实践补充

大三上汇编课程的个人项目留档：用 16 位 8086 汇编实现 DOS 文本模式俄罗斯方块。源码围绕寄存器、栈、寻址、BIOS 输入与时钟、显存写入组织游戏程序，采用 NASM 语法。

工程见 [tetris8086](tetris8086/README.md)，包含源码、macOS/Windows 构建与启动脚本、原有机器码测试、设计说明和一张游戏截图。

原留档的 [验证记录](tetris8086/docs/验证记录.md) 写明 2026-09-15 在 macOS 上用 NASM、DOSBox-X 验证，并记录 25 项自动测试通过。该记录属于当时工程记录，**本次归档未重新汇编或执行测试**；Windows 与 MASM/TASM 兼容性也没有被本次验证。

本快照没有包含 `.COM`、汇编清单或工具二进制，先按子目录说明从源码构建；原说明里提到的预编译文件需要自行生成。课程讲义、教材扫描件、教师课件、同学资料和个人成绩截图未包含。

夏季数字逻辑已经在[数字逻辑栏目](../digital-logic-labs/) 中留档，本次不重复复制。夏季广告灯升级说明显示其基于学长工程，且升级版未在 Quartus 编译；夏季体系结构与云管理课程原报告留在本地证据索引，本目录未复制这两门的报告原件。来源为课程项目本地文件、历史验证记录与成长报告。
