# Data Structures Team Lab — Labeled Binary Tree

上海大学 2025—2026 学年春季数据结构课程合作实验的源码节选。保留的 `ex4_2.cpp` 对应“标记二叉树”路径统计，提供递归、逐步回退和批量回退三个实现，主程序调用批量回退版本。

## Build and input

```sh
g++ -std=c++17 ex4_2.cpp -o labeled_tree
```

输入第一行为测试组数，随后每行输入正整数 `a b`；输出从根 `(1,1)` 到该标记所经过的左、右分支次数。按源码，非法标记返回 `-1 -1`。示例输入：

```text
2
42 1
3 4
```

报告所列对应输出：

```text
41 0
2 1
```
