# Fly-to-EEG：连接组仿真与前向观测原型

这是从个人研究工作区整理的精选源码快照，保留 AI 辅助开发痕迹与上游方法归属。它不是完整实验归档，也不是已发表成果。整理时未执行训练、仿真或重新计算科研结果；以下数字均为原工作区历史记录。

本方向探索真实果蝇连接组活动是否可能通过受约束的人工皮层和人头前向模型，产生用于人类运动想象 EEG 的合成数据。当前完成的是工程与数值先导；人工皮层、合成头皮 EEG 和人类迁移任务尚未完成。

- [自有核心模块](src/)：连接组接口、连续动力学、策略读出、身体映射、膜电流及电极观测。
- [运行与汇总脚本选集](scripts/)及[模型配置](configs/)。
- [数值检查代码选集](tests/)：保留原检查源码，本次未执行。
- [历史结果与限制](HISTORICAL_FINDINGS.md)。
- [上游依赖与归属](ATTRIBUTION.md)。

## 运行范围

保留了三类自有 `src` 模块和对应主要脚本，但未打包 Male CNS 原始连接组、SWC 形态、处理后子图、源活动、上游 hybridLFPy 或结果数组。运行前须按配置准备合法数据与依赖。源记录和全流程交接脚本也没有全量复制，因此这是精选模块，完整先导复现仍需原工作区。

依赖记录位于本目录的 `requirements-*.txt`；这些是原工作区记录，不是本次验证过的全新环境。请先阅读代码和配置，避免直接触发大规模连接组加载。此快照没有附带已通过测试的承诺。
